# ⚡ Life OS - Digital Command Center

> "Control your digital life, or it will control you."

Life OS is a personal, cyberpunk-themed digital command center built to track, manage, and optimize everyday life. From deep coding sessions to personal finances and secure vaults, everything is managed from a single, unified dashboard.

## 🚀 Features

*   **Dashboard View:** Live metrics, active checklist, and system status.
*   **Accounts Hub:** Manage and track 2FA/security details for all accounts.
*   **Documents Vault:** Securely store and download important PDF files and ID proofs.
*   **Finance Tracker:** Track income, expenses, and transaction history.
*   **Goals & Habits:** Maintain streaks for workouts, coding, and discipline.
*   **Projects Hub:** Track software development progress and deployments.
*   **College & Study:** Manage subjects, notes, and academic progress.
*   **Entertainment:** Track currently watched anime, movies, and games.
*   **Security Center:** System alerts and overall security score.

## 🛠️ Tech Stack

*   **Frontend:** React (Vite), Tailwind CSS, Lucide React Icons
*   **Backend:** Node.js, Express, Local JSON DB (Preparing for MongoDB)
*   **Authentication:** JWT (JSON Web Tokens) & bcryptjs

## 💻 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/move-on-D/LIfeOs.git
   cd LIfeOs
   ```

2. **Start the Backend:**
   ```bash
   cd backend
   npm install
   npx nodemon server.js
   # Runs on http://localhost:5000
   ```

3. **Start the Frontend:**
   ```bash
   cd frontend
   npm install
   npm run dev
   # Runs on http://localhost:5173
   ```

## 🔐 Accessing the Vault
On the first run, click **"Initialize Vault"** on the login screen to create your master operator ID and password.
